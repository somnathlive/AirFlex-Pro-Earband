# AirFlex Pro Earband – Responsive Product Card

A modern, responsive, and interactive product card UI built using **HTML5, CSS3, and JavaScript**. This project showcases a premium e-commerce product page with an image gallery, product customization, quantity selection, wishlist functionality, and add-to-cart notifications.

## Project Overview

The AirFlex Pro Earband Product Card is a front-end web development project designed to provide a clean, user-friendly, and visually appealing online shopping experience.

The interface features a modern layout, smooth hover animations, interactive product options, and a responsive design that works across desktop, tablet, and mobile devices.

## Features

* **Responsive Design:** Compatible with desktop, tablet, and mobile screens.
* **Product Image Gallery:** Switch the main product image using thumbnails.
* **Product Color Selection:** Choose from Black, Blue, Green, and Red.
* **Size Selection:** Select the preferred size from 38 to 46.
* **Quantity Selector:** Increase or decrease product quantity (1–10).
* **Wishlist Button:** Toggle wishlist selection.
* **Add to Cart:** Display selected color, size, and quantity in a notification.
* **Interactive Notifications:** Show feedback for product selections and cart actions.
* **Modern UI:** Gradient backgrounds, rounded corners, shadows, and smooth hover effects.
* **Product Information:** Display product price, discount, ratings, and features.

## Getting Started
Follow these steps to run the project on your local machine.
### 1. Clone the Repository
```bash
git clone https://github.com/somnathlive/Product-Card/AirFlex-Pro-Earband.git
```
### 2. Navigate to the Project Folder
```bash
cd AirFlex-Pro-Earband
```
### 3. Open the Project
Open the `index.html` file in your preferred web browser.
Alternatively, open the project in Visual Studio Code and run it using the **Live Server** extension.
No database, backend, or additional dependencies are required.

##  How to Use

1. Open the product card in your browser.
2. Click the thumbnails to switch product images.
3. Select your preferred product color.
4. Choose a product size.
5. Use the `+` and `−` buttons to adjust the quantity.
6. Click the heart icon to toggle the wishlist.
7. Click **ADD TO CART** to display the selected product details in a notification.
